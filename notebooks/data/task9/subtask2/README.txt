SemEval 2027 Task 9 - Framing in Images (Subtask 2)
Training data, chunk 1: 400 English article-image pairs

All 400 items in this package are training data for participants.

For each document, the raw-document folder contains three files:
  EN_M_TRAIN_doc_1.txt     The article as UTF-8 plain text.
  EN_doc_1_image.jpg      The corresponding image.
  index1.html            Plain HTML displaying the article beside the image.

Documents are numbered from 1 to 400.

Open index<number>.html directly in a browser to view an article and its image.
Keep the image in the same folder as the HTML file.

HTML file work offline and contain no CSS or JavaScript. The plain-text
article has its title on the first line, followed by a blank line and the body.

Annotations and the label list are supplied in the separate annotations folder.

Source: https://github.com/YovaKem/mm-framing-baselines
